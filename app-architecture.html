📱 App Architecture Blueprint

How FraudShield Sends Real
Scam Notifications

A complete technical breakdown of how a real mobile app reads your SMS, calls, and links — and fires an instant alert before you lose money.

The Core Challenge

A website can only scan messages you manually paste. A real app reads messages automatically in the background — the moment they arrive — and shows an alert without you doing anything.

📩

SMS / WhatsApp

App listens for new SMS messages using an OS background service, scans text instantly, fires notification if suspicious.

📞

Incoming Calls

App reads caller ID, checks it against known scam number databases, and shows a warning overlay on the call screen.

🔗

Links & URLs

When you tap any link, a background scan checks if it's a phishing domain before your browser even opens it.

How It Works — Step by Step

What happens the moment a scam message hits your phone

1

📩 Message Arrives

An SMS or WhatsApp message lands on your phone. The OS delivers it to all registered listeners.

SMS_RECEIVED broadcast
2

🧩 Background Service Wakes Up

FraudShield's background service catches the broadcast even when the app is closed. No user action needed.

BroadcastReceiver WorkManager
3

🧠 AI Engine Scans Text

The scam detection engine runs locally on your device — no internet needed. Checks for OTP requests, UPI IDs, urgency words, phishing links, and 7+ scam patterns.

On-device ML / Rule engine
4

📊 Risk Score Calculated

A score from 0–100 is generated in milliseconds. If score ≥ 31, a notification is immediately triggered.

< 100ms latency
5

🔔 Notification Fired

An alert appears on your lock screen, notification tray, and as a heads-up banner — with the risk score and [Check Details] button.

NotificationManager PendingIntent
6

📱 Tap → Full Report Opens

Tapping the notification opens FraudShield directly on the result screen showing why the message was flagged, safety advice, and report options.

Android vs iOS vs Web

Each platform has different levels of access to SMS, calls, and links

Android
🤖

Full Access — Best for FraudShield

  • Read SMS in background ✅
  • Intercept calls before answer ✅
  • Scan links from any app ✅
  • Works even when app is closed ✅
  • Run background services ✅

Built with: Android SDK (Kotlin/Java) or React Native / Flutter

iOS (iPhone)
🍎

Limited — Only Call & Link Filtering

  • Read SMS in background ❌ (blocked by Apple)
  • Call Directory Extension ✅ (flag callers)
  • Safari Content Blocker ✅ (block phishing)
  • Background services very limited ⚠️
  • Push via APNs server ✅

Built with: Swift / React Native, CallKit, MessageFilter

Web (PWA)
🌐

Manual Only — Our Current Website

  • Read SMS ❌ (browser can't access SMS)
  • Read calls ❌
  • Paste & scan manually ✅
  • Browser Push Notifications ✅ (with permission)
  • Install as app on home screen ✅ (PWA)

Built with: HTML/CSS/JS + Service Worker (PWA)

Recommended Tech Stack

How to actually build the FraudShield mobile app

⚛️

React Native (Recommended)

Write one codebase, deploy on Android AND iOS. Use react-native-sms-retriever for SMS reading on Android. Works with Expo for rapid prototyping.

🐦

Flutter (Alternative)

Google's cross-platform framework. Use telephony plugin for SMS and flutter_phone_state for call detection. Beautiful UI out of the box.

🤖

Native Android (Kotlin)

Most powerful option. Full access to all Android APIs. Use BroadcastReceiver + WorkManager for robust background scanning. Best performance.

🧠

On-Device AI (TensorFlow Lite)

Run the scam detection model locally on device — no internet required, zero privacy risk, instant response. TFLite model can be under 2MB.

🔥

Firebase (Backend)

Firebase Cloud Messaging (FCM) for server-push notifications. Firestore for real-time scam database sync across all users. Firebase Auth for accounts.

🌐

PWA (Quick MVP)

Our current website can be made installable as a Progressive Web App. Add a Service Worker + manifest.json — users install it from browser, get push notifications.

📞 How Call Scam Detection Works

When someone calls you, FraudShield checks the number before you even answer

1

Phone Rings

Android fires PHONE_STATE broadcast with caller's number.

TelephonyManager.CALL_STATE_RINGING
2

FraudShield Wakes Up

Background receiver intercepts the number — works even when app is closed.

3

Number Checked

Number checked against local scam DB + live Chakshu/community database via API.

Local cache REST API
4

Warning Overlay Shown

A heads-up notification or full-screen overlay appears while the phone is still ringing — you see the risk before answering.
